# UI参考調査: Friends & Fables / Roadwarden

- 調査日: 2026-08-01
- 調査方法: Antigravity CLI（Gemini 3）による Web 調査＋Roadwarden は Steam 公式スクリーンショット4枚（本ディレクトリ `roadwarden/s1.jpg`〜`s4.jpg`）を取得し目視で裏取り
- 目的: 本プロジェクトのゲーム画面（UI）設計の参考。反映先は仕様書 v0.8 §6 と実装仕様書 PR-18

## 1. Friends & Fables（AI TRPG / Webサービス）

AI GM「Franz」が D&D 5e SRD でゲームマスターを務めるフリーミアムの Web サービス。
**設計思想が本プロジェクトと同型**: ステータス・HP・インベントリ・ダイス計算はコード/DB 側が
Single Source of Truth で、AI は描写と NPC 台詞に専念する（本プロジェクトの INV-1/2 に相当）。

### 画面構成

「AIチャットボット」ではなく **VTT（仮想卓）＋AIチャットの統合画面**。

- 中央: 物語ログ（情景描写・NPC会話・イラスト）。下部に入力欄＋マイク＋手動ダイスアイコン
- 左パネル（折りたたみ可）: ワールドマップ、クエストログ、ロア、セッション履歴、設定
- 右パネル: キャラクターシート常時表示（HPバー、AC、能力値、呪文スロット、インベントリ）
- 判定表示: ダイス回転アニメーション → ログ内に**埋め込みリッチカード**
  （`出目＋修正値＝合計 vs DC`、成功=緑／失敗=赤の色分け）
- 戦闘: グリッド付きトップダウンマップがオーバーレイ切替、イニシアチブバーで行動順表示
- 地の文／NPC台詞／システムメッセージを**フォント・枠・背景色の異なるカードで区別**
- `OOC:` プレフィックスでメタ操作をロールプレイと分離

### 評価

- 好評: DM 不要の 5e 体験、シート自動管理＋ダイス演出の統合、状態とAI描写の分離
- **不評: 1画面に詰め込みすぎで初見に情報過多（"Busy UI"）**。長期プレイでのAIの記憶減衰

### 情報源

- https://fables.gg / https://fables.gg/pricing / https://help.fables.gg/
- レビュー・コミュニティ系はサイト名のみで裏取り弱め（DungeonsDeep.ai、Reddit r/friendsandfables 等）。
  レイアウト細部は公式ヘルプ・公式動画での再確認を推奨

## 2. Roadwarden（テキストRPG / Steam 買い切り ¥1,120）

Moral Anxiety Studio 開発（Ren'Py 製）、Steam「圧倒的に好評」クラスのピクセルアート
テキストRPG。メイン約11.5時間。選択肢ベース＋NPC への自由テキスト入力のハイブリッド。
判定はダイス非表示の決定論的処理（職業・所持品・知識・準備・態度で成否決定）。

### 画面構成（スクリーンショットで検証済み）

**3カラム固定レイアウト**。濃紺スレート地にローズベージュの文字・罫線で全体を統一。

- **左カラム（約35%）** — `s2.jpg` `s3.jpg`: 現在地・NPC のピクセルアートイラスト。
  UI と同一パレット。重要イベントではイラストが全画面化し、中央に半透明テキストボックスのみを
  重ねる演出（`s1.jpg` オープニング）
- **中央カラム（約45%）**: 地の文・会話テキスト。人名・地名は**インラインで明色ハイライト**
  （`s2.jpg` の「A woman in yellow armor」「Hovlavan」）。水平罫線を挟んで下に選択肢リスト
  （プレーンテキスト、ホバーで白く明るくなる）。会話時は**態度選択が5つのアイコンボタン**
  （握手・唇・無表情・拳・涙目）として並び、ホバー中の説明ラベルは左カラム下部にオーバーレイ表示
- **右カラム（約20%）**: 上部にテキストメニュー2列（Character / Inventory / Wait / Map /
  Sleep（状況で Seek Shelter に変化・グレーアウト）｜Settings / Q.Save / Q.Load / Archive /
  Journal）。下に**数値やゲージを使わないアイコン式ステータス**（太陽の位置=時刻、ハート=体力、
  椀=栄養、服=防具/身だしなみ、月=夜間）
- **インベントリ等は専用の全画面ビュー**（`s4.jpg`）: 左に縦メニュー、右にアイテム＋説明＋
  「Open and drink / Open and smell」の選択肢。**アイテム操作も本文と同じ選択肢UIの文法で統一**
- 画面上端に所持品クイックアイコン列が並ぶ場面あり（`s3.jpg`）
- フォント: ピクセルフォント⇔セリフ体（可読性重視）の切替オプションあり

### 評価

- 高評価: 文芸的な文章と厳格なリソース管理の融合、1画面に「イラスト・本文・状態」が収まる
  没入感、態度アイコンによる「プレイヤー宣言」のUI化
- 不評: 自由入力パーサーの厳格さ（後に改善）、英文の文字量、初期の40日制限（後に緩和モード追加）

### 情報源

- https://store.steampowered.com/app/1155970/Roadwarden/ （価格・ジャンル・スクリーンショットは Steam API で取得確認済み）
- https://moralanxiety.itch.io/roadwarden
- Metacritic 83、HowLongToBeat 約11.5h は Web 調査値（独立検証なし）

## 3. 本プロジェクトへの反映（仕様書 v0.8 §6 に採用）

1. **3エリアレイアウト**（Roadwarden）: 左=シーンビジュアル、中央=物語ログ＋選択肢＋自由入力、
   右=コードが管理する真のゲーム状態。「右パネルの表示値は GameState のみを情報源とする」ことで
   INV-1（真実はコード側）を画面構成そのものに対応させる
2. **判定のログ内カード表示**（F&F）: `出目＋修正＝合計 vs 閾値` を tier 色分けで埋め込み。
   判定の公正さを見せる差別化ポイント（仕様書 §6 の判定演出の具体化）
3. **テキスト種別のスタイル区別**（F&F）: 地の文／NPC台詞／システムメッセージを視覚的に分ける
4. **重要語のインラインハイライト**（Roadwarden）: RichTextLabel の BBCode で再現可能
5. **情報密度の抑制**（F&F の反面教師）: 常時表示は最小限に絞り、詳細は全画面ビューへ
   （Roadwarden のインベントリ方式）
6. **サジェストボタン＝閉じた語彙のプレイヤー宣言**（Roadwarden の態度アイコンの発想）:
   INV-3（閉じた語彙）と整合する入力補助
